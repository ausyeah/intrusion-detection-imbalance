# 不平衡比例敏感性衰减（预注册判定）

- 协议：训练划分非 Normal 类降采样至 p ∈ {1.0, 0.5, 0.25, 0.1}（Normal 不动），XGBoost none/类别权重，3 种子；valid/test 不操纵；p=1.0 复现第 3 周对应格子。
- 预注册判定（红队三轮 A1-1/A2-2 修订，口径限定）：两方法在 p=0.25 时 Macro-F1 降幅均 < 0.02——**仅 Macro-F1 口径、且仅在 p≥0.25 范围内**判稳健。三个限定必须随行披露：
  1. 少数类宏 Recall 同步大幅衰减（p=1.0→0.25：none -0.104、类别权重 -0.138；p=1.0→0.10：none -0.197、类别权重 -0.317）——「不平衡处理方法的价值」应表述为「在较轻不平衡下保住 Macro-F1」，**不是**「保住少数类召回」；
  2. none 在 p=0.10 的 Macro-F1 降幅 0.0417（0.5097→0.4680）已超出 <0.02 准则自身，p=0.10 不在稳健结论覆盖范围内；
  3. 本判定不外推到 SMOTE（本实验仅跑 none/类别权重，SMOTE 衰减曲线未生产，如需对比须补跑）。
- 可复现性声明（红队三轮 A1-3）：XGBoost（none/类别权重）为确定性算法，且 13_imbalance_decay.py 的降采样 RandomState 仅依赖比例索引、不随 seed 变化，故 3 种子结果完全相同（std=0）——std=0 表示可复现性而非稳健性，本实验的种子轴退化为单条件重复。
