# 预注册：方法排序稳定性检验（回溯性预注册）

日期：第 6 周（07-21 ~ 07-27）。**性质声明（诚实优先）**：本预注册为回溯性预注册——第 3 周报告中
已可见排序事实，不存在盲测条件。其用途是**在计算前冻结判定标准与统计口径**，防止
事后挑选支持性数字；不声称、也不应被解读为盲测预注册。

## 待检验命题

- H1（选型分割）：方法排序在验证集口径与测试集口径之间不稳定。
- H2（指标口径）：方法排序在 Macro-F1 与 Balanced Accuracy / 少数类宏 Recall 之间不稳定。
- H3（模型）：方法排序在不同模型之间不稳定。

## 冻结的统计口径（计算前固定）

1. 排序对象：4 种处理方法（none / class_weight / ROS / SMOTE）。
2. 排序依据：3 种子均值（数据源 runs/experiments/summary_full.csv，与第 3 周
   stability CSV 同源）。
3. 统计量：Kendall τ（scipy.stats.kendalltau，方法间两两比较不涉及，直接对 4 方法
   排序向量计算）。
4. 比较对（共 15 组，计算前列全，不得增删）：
   - 选型分割间（3 组）：每模型 valid_macro_f1 排序 对 test_macro_f1 排序。
   - 指标间（6 组）：每模型 test_macro_f1 排序 对 test_balanced_acc 排序；每模型
     test_macro_f1 排序 对 少数类宏 Recall 排序。
     少数类集合（预注册定义）：训练集样本数 ≤ 2,000 的 4 类——Analysis（2,000）、
     Backdoor（1,746）、Shellcode（1,133）、Worms（130）；少数类宏 Recall = 这 4 类
     测试 Recall 的简单平均。
   - 模型间（6 组）：每指标（test_macro_f1、Balanced Accuracy）下 LR 排序 对 XGBoost
     排序、XGBoost 对 MLP、LR 对 MLP。
5. 判定标准（冻结）：τ ≥ 2/3 → 方向基本一致；1/3 ≤ τ < 2/3 → 部分一致；
   τ < 1/3 → 不一致。任一组平均 τ < 2/3 即支持对应命题。

## 冻结的局限声明

- n = 4 方法的 τ 取值离散（{-1, -2/3, …, 2/3, 1}），统计功效低：τ 必须与完整排序表
  一并报告，单独的 τ 值不构成结论。
- 比较对共 15 组，存在多重比较；本检验只做描述性结论（排序是否稳定），不做显著性
  p 值宣称。
- 回溯性预注册的固有限制见顶部性质声明。
