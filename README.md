## 背景与动机

网络入侵检测系统（Network Intrusion Detection System, NIDS）是网络基础设施纵深防御的重要防线。在实际通信网络中，流量数据呈现极端的类别不平衡性（良性流量占绝大多数，而 Worms、Backdoor 等定向高危攻击极其稀缺，在 UNSW-NB15 中不平衡比高达 431:1）。常规机器学习检测器倾向于迎合多数类以获取较高的总体准确率（Accuracy），导致高危少数类遭受系统性漏检。

针对类别不平衡问题，现有文献广泛采用了重采样（ROS/SMOTE）与代价敏感学习（类别加权）等策略。然而，以往实证研究普遍存在**实验协议不统一、缺乏严密的防数据泄漏约束、忽略测试集固有标签冲突，以及脱离网络设备吞吐时延约束**等局限。本项目旨在：
1. 建立严格防泄漏的受控实证评测基准，定量评估不同不平衡处理策略的适用边界；
2. 结合通信网元对低时延与线速吞吐（Line-rate throughput）的现实工程约束，探索零重训练阈值校准与特征筛选轻量化方案。

## 核心实证发现

| 核心发现 | 实证结果与定量观察 | 物理与工程意义 |
|---|---|---|
| **不平衡处理相对优势依赖分类器类型** | 选型分割间方法排序 Kendall τ：LR +1.0（偏好 SMOTE）/ XGBoost −1.0（偏好类别加权）/ MLP +0.333 | 在受控设置下，处理方法的有效性与分类器模型强耦合，不存在单一通用的最优解。 |
| **最高 Macro-F1 源自零重训练后处理** | 验证集后处理阈值校准 Macro-F1 达 **0.5436 ± 0.0063**，优于全部 36 组训练期处理组合 | 避免了耗时繁琐的样本重平衡训练，为算力受限网元提供了极低开销的后处理路径。 |
| **特征筛选实现显著训练加速** | 增益筛选保留 32 维核心特征，取得 **2.67× 训练加速**，Macro-F1 损失在切分方差内（−0.0022） | 大幅削减特征抽取与高维计算负载，贴合网络交换机/边缘网关线卡的处理瓶颈。 |
| **少数类召回对训练样本偏斜度高度敏感** | 随训练集少数类比例衰减至 10%，加权方案的宏 Recall 从 0.663 系统性下降至 0.331 | 揭示了真实网络流量漂移或攻击极度稀缺时，常规算法召回率的性能衰退边界。 |

## 复现说明

运行环境：Windows 11 · Python 3.13.15 · scikit-learn 1.9.0 · XGBoost 3.4.1 · imbalanced-learn 0.14.2（精确版本依赖见 `requirements.lock.txt`）。

```bash
# 1. 创建并激活虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 2. 安装锁定依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 按序执行核心流水线
python src/01_eda.py                # 数据分布核验与 EDA
python src/02_preprocess.py         # 防泄漏预处理（严格先切分后拟合）
python src/05_run_experiments.py    # 36 组主实验矩阵（幂等断点续跑）
python src/07_error_analysis.py     # 64 位行哈希错误归因
python src/08_lightweight.py        # 特征筛选轻量化实验
python src/13_imbalance_decay.py --v2   # 稳健性检验与重切分方差补测
```

### 严格防数据泄漏协议
1. **作用域严格隔离**：连续变量标准化、类别编码与重采样策略（ROS/SMOTE）**仅在训练集拟合（fit）**，验证集与测试集仅做转换（transform）。
2. **超参选取与评估隔离**：超参数选取与阈值校准仅在验证集执行，官方测试集终身单次前向评估，杜绝测试集信息泄漏。

## 质量与可复现性保障

- **全流程自查闭环**：建立了严格的实验规范自审机制（涵盖指标对应、选型隔离、统计检验与切分敏感性，37 项发现全部闭环留痕于 `reports/redteam/`）。
- **实证严谨性**：超参数单一配置源（`configs/`）、严格环境锁定、每个实验格点自动落盘参数与评价指标。
- **诚实陈述局限**：主动报告负结果（如特征筛选无法有效压缩树模型离线体积、少数类召回在严重偏斜下的衰减），并在论文第 7 章完整公开方法适用边界与已知局限。
